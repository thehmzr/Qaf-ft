Qaf-ft system

Progress page

A speech model for Quran recitation that writes down the sounds it hears and compares them with the expected ayah, so a mistake is located at the word and named. This page is the technical reference: how it works, how it is trained and labelled, and what has been measured.

01The task

The reciter reads a known ayah. The model does not see the text: it listens and writes a sequence of sounds. A separate checker compares that sequence with the sounds the ayah should have. Keeping the model blind to the text is deliberate; models that output Quran text quietly correct mistakes back to the memorised wording.

02Sound tokens

Text is converted to sounds by rule, not by ear: an open phonetic script for the Quran applies the tajweed rules to the Uthmani text. It writes a lengthened sound as a repeated symbol. Repeats are folded into one token with a count, which keeps sequences short and guarantees no two neighbouring tokens are equal.

KindTokensWhat the count means
Consonants28 letters, plain or doubled (ب, ب2)2 = shaddah or merged with the next word

81 tokens in total, built by running the converter over all 6,236 ayahs with madd settings of 2, 4 and 6. A median ayah is 69 tokens.

04The checker

For every expected word the checker asks two questions and keeps the worse answer.

Thresholds are set from correct recitation by reciters the model never trained on: a word's score is compared with the scores of known-correct words, and the cut-off is chosen for a fixed share of false flags.

05Why the false-flag rate has to be tiny

Each word is a separate decision, so small per-word rates add up over an ayah and a session.

Chance of at least one false flag, assuming independent words: 1 − (1 − rate)words. The working target is 0.1% or lower, which is why results below are reported at 0.1% as well as 1%.

08Labelling

Every labelled clip stores what should have been said and what was said, the same pairing the strongest published systems train on. The tool runs on the labeller's own computer and nothing leaves it.

10Data and licence position

The trained model contains NVIDIA's Arabic checkpoint (credit required) and an openly licensed set of expert recitations. Nothing with a non-commercial or share-alike licence has been used, so the licence of the model stays a free choice as long as credits are kept. Datasets whose licences would dictate the model's own licence are excluded. Credits are listed in the repository.
